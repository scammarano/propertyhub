# Internet de invitados y vouchers

## Propósito

Gestiona vouchers y acceso de invitados, principalmente mediante UniFi Network.

## Capacidades

- `wifi_vouchers`
- `guest_portal`
- `quotas`
- `validity`
- `visitor_links`
- `reservation_links`

## Estado 0.6.0

Vista y esquema; integración real con UniFi/portal cautivo está pendiente.
