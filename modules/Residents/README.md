# Residentes y relaciones con unidades

## Propósito

Gestiona propietarios, inquilinos, familiares, empleados y representantes vinculados a unidades.

## Capacidades

- `owners`
- `tenants`
- `family_members`
- `employees`
- `representatives`
- `membership_validity`

## Estado 0.6.0

Esquema y demo disponibles; CRUD persistente, documentos, vigencias y aprobaciones están pendientes.

## Reglas

- Respetar permisos y alcance por instalación/unidad.
- Usar persistencia, auditoría y validaciones antes de declarar estable.
- Seguir las reglas de grids, modales, filtros y paginación.
- No presentar una vista demo como integración productiva.
