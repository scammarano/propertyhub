# Reservas de áreas

## Propósito

Gestiona disponibilidad, solicitudes, aprobación, rechazo, bloqueos y calendario de espacios comunes.

## Alcance

- Calendario de solicitudes.
- Validación de solapamiento.
- Aprobación manual o automática.
- Historial, cancelación, tarifa y depósito.
- Futuro vínculo con pago, voucher y acceso temporal.

## Estado 0.6.0

El flujo demo valida horarios en sesión. Las tablas existen, pero falta repositorio persistente, CRUD completo, pagos y activación de accesos.

## Reglas

- Respetar permisos en servidor.
- Mantener migraciones y manifiesto versionados.
- Aplicar reglas de grids, modales, filtros y paginación del estándar del proyecto.
- Actualizar este README cuando cambie el estado funcional.
