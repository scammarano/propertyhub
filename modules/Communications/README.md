# Cartelera y notificaciones

## Propósito

Agrupa cartelera, avisos operativos, emergencias y entregas por canal.

## Alcance

- Publicaciones por audiencia y vigencia.
- Racionamiento, cortes y mantenimiento.
- Notificación in-app.
- Directorio de emergencias.
- Futuro push, correo, WhatsApp, SMS y perifonía.

## Estado 0.6.0

Las pantallas y el flujo in-app son demo de sesión. El modelo de base está preparado; canales externos están pendientes.

## Reglas

- Respetar permisos en servidor.
- Mantener migraciones y manifiesto versionados.
- Aplicar reglas de grids, modales, filtros y paginación del estándar del proyecto.
- Actualizar este README cuando cambie el estado funcional.
