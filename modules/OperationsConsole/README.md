# Operations Console

## Propósito

Consola web para administración, vigilancia, recepción, operadores y soporte técnico.

## Alcance

- Dashboard y menús por permiso.
- Gestión de propiedad y comunidad.
- Calendarios y aprobaciones.
- Inventario, conectores, diagnóstico y actualizaciones.

## Estado 0.6.0

Navegación y vistas disponibles. Varios grids y acciones continúan en demo; se requiere CRUD persistente y paginación server-side.

## Reglas

- Respetar permisos en servidor.
- Mantener migraciones y manifiesto versionados.
- Aplicar reglas de grids, modales, filtros y paginación del estándar del proyecto.
- Actualizar este README cuando cambie el estado funcional.
