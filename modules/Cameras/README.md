# Cámaras y video

## Propósito

Gestiona inventario, permisos y futura visualización de cámaras/NVR multimarca.

## Capacidades

- `camera_catalog`
- `live_view`
- `recordings`
- `ptz`
- `audio`
- `permissions`

## Estado 0.6.0

Vistas demo y esquema; ONVIF/RTSP/WebRTC/HLS reales están pendientes.

## Reglas

- Respetar permisos y alcance por instalación/unidad.
- Usar persistencia, auditoría y validaciones antes de declarar estable.
- Seguir las reglas de grids, modales, filtros y paginación.
- No presentar una vista demo como integración productiva.
