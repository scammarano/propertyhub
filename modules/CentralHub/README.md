# Property Hub Central Console

## Propósito

Consola superior para instalaciones, tokens, versiones, APIs, conectores, salud, privacidad y métricas agregadas.

## Alcance

- Expedientes de nuevas instalaciones.
- Registro de Property Nodes.
- Portafolio y salud.
- APIs y releases.
- Tokens y políticas de datos.

## Estado 0.6.0

El núcleo del Central es persistente y funcional como base. El soporte remoto detallado y el motor completo de aplicación/rollback de actualizaciones están pendientes.

## Reglas

- Respetar permisos en servidor.
- Mantener migraciones y manifiesto versionados.
- Aplicar reglas de grids, modales, filtros y paginación del estándar del proyecto.
- Actualizar este README cuando cambie el estado funcional.
