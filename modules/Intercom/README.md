# Intercomunicación y perifonía

## Propósito

Integra telefonía IP, videoporteros, intercomunicadores y perifonía.

## Capacidades

- `sip`
- `extensions`
- `door_intercom`
- `call_groups`
- `paging_zones`
- `announcements`

## Estado 0.6.0

Vista y contratos de conectores; no realiza llamadas ni anuncios reales.

## Reglas

- Respetar permisos y alcance por instalación/unidad.
- Usar persistencia, auditoría y validaciones antes de declarar estable.
- Seguir las reglas de grids, modales, filtros y paginación.
- No presentar una vista demo como integración productiva.
