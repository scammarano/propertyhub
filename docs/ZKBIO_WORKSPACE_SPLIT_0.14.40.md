# ZKBio Workspace Split — 0.14.40

La pantalla `zkbio-lab` del Property Node deja de presentar todos los flujos como una única página vertical.

## Espacios de trabajo

1. **Unidades y personas**: conciliación Property ↔ Departamento ZKBio, adopción masiva/global, adopción por unidad y selección individual.
2. **Puertas y accesos**: puertas descubiertas, adopción/ubicación estructural y prueba controlada de apertura.
3. **Herramientas / diagnóstico**: conciliación manual Persona ↔ PIN, pruebas Node → Edge → ZKBio y cola operativa.

## Unidades colapsables

Cada unidad muestra sólo el resumen (departamento, conteo, estado y acciones). El contenido de personas/vehículos queda cerrado por defecto y se abre bajo demanda. También existen controles globales Expandir/Colapsar.

## Densidad visual

Las tarjetas KPI usan menor padding, número más pequeño y tablas `table-sm`, reduciendo altura sin eliminar información.
