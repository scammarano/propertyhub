# Actualización 0.9.1 → 0.9.2

1. Respalda la carpeta y la base de datos.
2. Conserva `.env` y `storage/`.
3. Sustituye los demás archivos por los de la versión 0.9.2.
4. Ejecuta `tools\migrate.bat` para registrar la versión. No hay migraciones SQL nuevas.
5. En el teléfono, cierra y vuelve a abrir la PWA. Si conserva la vista anterior, elimina el acceso instalado y agrégalo nuevamente o limpia los datos del sitio.
6. En navegador de escritorio o móvil, realiza una recarga completa.

La consola administrativa y los datos operativos no se modifican.
