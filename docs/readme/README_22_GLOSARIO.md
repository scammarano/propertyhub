# Glosario

**Property Hub:** nombre del producto.

**Property Hub Central:** fuente oficial, repositorio y portafolio superior.

**Property Node:** instalación operativa de una propiedad o complejo.

**Instalación:** despliegue independiente con carpeta, base, UUID y configuración propios.

**Propiedad / complejo:** urbanización, edificio, conjunto, oficina, comercio, campus o instalación mixta administrada.

**Unidad:** apartamento, casa, parcela, oficina, local, depósito u otra unidad ocupable.

**Resident App:** experiencia PWA/móvil del usuario final.

**Operations Console:** consola administrativa y de vigilancia.

**Conector:** componente que implementa una API/protocolo de fabricante.

**Instancia de conector:** configuración local concreta de un conector, por ejemplo “ZKBioSecurity principal”.

**Capacidad:** función declarada por un conector o dispositivo, como abrir, emitir PIN o ver PTZ.

**Punto de acceso:** puerta, portón, barrera, torniquete, ascensor o cerradura.

**Credencial:** tarjeta, tag, PIN, QR, huella, rostro, NFC o móvil.

**Membresía:** relación autorizada entre usuario/persona e instalación/unidad.

**Expediente de instalación:** preparación creada en Central antes de desplegar el nodo.

**Token de registro:** secreto de uso limitado para vincular un nodo.

**Heartbeat:** reporte periódico de estado y versiones.

**Telemetría agregada:** métricas sin datos personales identificables.

**Release:** versión publicada de un componente.

**Manifiesto:** metadatos firmados de un release o catálogo.

**Canal:** development, beta, stable o pinned.

**Gateway tecnológico:** equipo propio de TTLock, LoRaWAN o video; no es otro Property Node.

**LoRaWAN:** red de largo alcance y bajo ancho de banda para sensores/IoT.

**Demo de sesión:** flujo visible cuyos datos viven temporalmente en la sesión PHP.

**Base funcional parcial:** implementación inicial que requiere completar casos productivos.
