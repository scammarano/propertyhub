# Property Hub Central vs. Property Node

## Property Hub Central

Es la fuente oficial del producto y el centro de supervisión. No sustituye las instalaciones locales ni funciona como base de personas de todos los clientes.

Ve:

- Instalaciones registradas.
- Nombre, código, tipo y URL del nodo.
- Versiones y canal de actualización.
- Salud, última conexión y colas.
- Conteos agregados.
- Tecnologías, conectores, APIs y cantidades de dispositivos.

No ve por defecto:

- Residentes y visitantes identificados.
- Documentos o fotografías.
- Historial individual de acceso.
- Contenido de carteleras o notificaciones.
- Usuarios y contraseñas de marcas.

## Property Node

Es la fuente operativa de cada inmueble. Allí viven la estructura, las personas, las reservas, los mensajes y la configuración de hardware.

## Dónde se configura cada marca

La configuración real se realiza en:

`Tecnología del edificio > Inventario tecnológico / Conectores configurados`

El Property Hub Central muestra una copia no sensible del inventario declarado mediante heartbeat.

## Soporte futuro

Una sesión de soporte podrá ampliar temporalmente el alcance, pero deberá:

1. Ser solicitada con justificación.
2. Ser aprobada localmente.
3. Tener alcance limitado.
4. Tener vencimiento.
5. Quedar auditada.
